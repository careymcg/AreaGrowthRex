Compare ss3 runs for GOA rex sole
================

This is a collection of stock assessment input files and plotting code
used to create a manuscript about the importance of accounting for
spatial growth patterns in statistical catch-at-age models when sources
of age data are missing, using Gulf of Alaska rex sole (Glyptocephalus
zachirus) as an example

## Installation instructions

install.packages(“devtools”)  
library(devtools)  
devtools::install_github(“careymcg/AreaGrowthRex”)
